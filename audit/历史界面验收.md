## 网页 UI / UX 三轮审计（2026-10-02）

使用本机 Chrome 实际点击、输入、搜索、下载并走完“选择口径/范围 → 探索规律 → 回测/试算 → 核对/导出”流程。第一轮审计流程并修复，第二轮检查视觉及响应式并修复，第三轮补足状态反馈与动效，再完成全部回归。

最重要的五项改进：

1. **导航与流程**：增加三步流程入口和首页规律线索；页面、规律类别、口径和筛选写入本地 URL，刷新、后退和首页入口能恢复正确状态。
2. **分析范围一致**：回测车型列表跟随全局分类和车型；日期错误明确提示并保留最后有效结果，避免静默调整另一端日期；提供完整批次/来源的展开说明。
3. **试算可信**：空白不作为0，真实0保留；预测天数须为正整数；负数、非法和溢出值提供字段关联错误，不输出误导结果。
4. **视觉与手机操作**：统一字级、间距、控件和 SVG 导航图标，实际操作控件至少44px；四个手机主入口完整可见；表格和长图表在局部滚动，不撑宽整个页面；提供键盘导航、跳过导航和可聚焦滚动区。
5. **动效与反馈**：切换和更新采用短过渡；连续操作取消旧动画；尊重“减少动态效果”；下载明确提示记录数和浏览器接管状态，无搜索结果时禁用导出并提示恢复方式。CSV仍保留原始数值，不限当前页。

浏览器开发回归（在 `销量规律` 项目根目录执行，需要开发机的 Node.js、Playwright 和 Chrome；内网使用网页与日常分析均不需要它们）：

```powershell
node tests/test_ui_workflow.cjs
```

若依赖不在默认 Node 搜索路径，可将 `PLAYWRIGHT_MODULE` 指向已安装的 Playwright 模块、`BROWSER_BINARY` 指向 Chrome；可传入 HTML 路径作为第一个参数。设置 `UI_AUDIT_SCREENSHOTS` 可保存桌面、手机和回测截图；默认不生成截图文件，也不将业务数据提交到仓库。

已验证27组浏览器检查：输入/错误恢复、分类/车型回测一致、有效回测图表与WAPE（浏览器内测试夹具，不写回业务数据）、刷新与后退、键盘操作、搜索与分页、净大定及锁单 CSV 原值、24类完整资料及其原值导出、首销结构与退订和分时样本（隔离夹具）、快速切换及减弱动效，以及320、375、390、768、844、1440、1920、2560、3840px九种视口的四个页面。113项Python测试通过；浏览器无脚本错误、无HTTP/HTTPS请求。

剩余验证边界：尚未在真实手机和读屏器上人工测试；2021年至今的内网全量数据不在本机，多年大数据规模下的性能需用真实数据复测。当前样例缺少有效评分回测、完整年度与节日窗口时，页面保留不足提示，不产生没有依据的规律；有效回测图表与16%/8%的WAPE展示使用隔离的UI测试夹具验证。现有已复现的阻塞流程问题已修复。

最终版本由无参数 `static/analyze_sales_patterns.py`生成，直接打开 `output_file/鸿蒙智行销量规律分析.html` 即可测试；主脚本不再生成 Excel，不增加线上服务或外部依赖。
