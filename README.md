# 销量规律分析与预测辅助

**研究宗旨：找各种规律是为了辅助销量预测。小订、留存大定、锁单分别发现规律、检验适用范围、做历史回测，不把三个口径合并。**

网页的业务口径固定为三个一级入口：小订使用原始汇总表的“小订数量”，且只允许查看小订期；留存大定使用源字段“留存大定”（兼容旧字段“净大定”）；锁单使用“交车锁单”。缺失字段明确显示，不用毛大定、大定或其他指标替代。小订转大定属于跨口径专题，只有车型、批次、时间窗口和分子分母能够匹配时才计算。

## 研究工作台结构

网页采用四个一级入口，每个问题只保留一个主要展示位置：

- **研究首页**：显示当前口径、车型范围、样本覆盖、已经发现的候选规律和下一步研究入口。首页只做摘要，不复制专题图表。
- **规律研究**：按“研究日历、阶段进度、订单关系”三个研究域组织月度/月内、星期与月末、节假日、上市后节奏、小订进度与退订、小时节奏、留存大定到锁单滞后等专题。
- **预测验证**：查看同车型、同口径、同阶段、同批次/来源的历史留出回测和单一倍率场景试算。历史P25/P75是分布范围，不直接称为预测区间。
- **数据证据**：查看逐日观测、留存大定到锁单配对记录和完整分析资料，支持搜索、分页和当前筛选 CSV 导出。

原来的首页趋势、周期倍率、车型对比和历史信号卡不再重复展示；趋势归入“规律研究 → 周期比例”，完整原值和来源归入“数据证据”。源表工作表不会机械地各生成一个菜单。

### 筛选原则

左侧是全局筛选：口径、车型分类、车型、销售阶段和日期范围会影响当前研究流程。切换口径时只保留仍然有效的车型和日期，阶段选项根据口径和源数据联动：小订只出现“小订期”（内部阶段值为“小订阶段”），留存大定与锁单按实际有效数据提供首销、平销等阶段；阶段未知只留在证据核对，不进入规律计算。小订和首销可能在同一天出现，但按指标分别判定，不能给整行订单套用一个阶段。

规律专题的节日、上市D天、小时指标等是专题筛选，只对当前问题生效。原始日历日期和上市后D天不能混用；完整资料中的记录必须能够追溯到源表字段、日期、批次和来源。真实0保留，缺失、负值、重复、不完整周期和缺少分母分别标记，不用补零制造规律。

研究主题是可操作的导航，不是装饰标签：点击“研究日历、阶段进度、订单关系”会进入该域最近一次查看的专题；当前口径不适用时仍允许进入，并在内容区说明“小订期/不适用”原因。专题里的“核对本专题证据”会继承当前曲线、周/月粒度、口径、车型和日期范围；证据页的搜索、分页、指标日期记忆会在刷新和浏览器后退时恢复。手机端默认收起全局筛选，点击“展开筛选”后再调整车型、阶段或日期。

双击项目根目录的 `启动静态销量规律.cmd`（旧 `启动销量规律.cmd` 作为兼容转发入口保留）；在 IDE 中运行时，将解释器设为所在 `Project/.venv`，直接运行 `static/analyze_sales_patterns.py`，程序参数留空。根目录 `analyze_sales_patterns.py` 保留为兼容转发入口。脚本只生成网页，完成后会按系统默认方式打开本次生成的 HTML：Windows 直接打开本地 HTML 路径，等同于双击文件，遵循 `.html` 的默认应用；其他系统使用默认浏览器。不指定 Chrome、Edge 或 IE，也不修改系统关联。若打开的浏览器与预期不同，请检查 Windows 的 `.html` 默认应用（可能与 HTTP/HTTPS 链接的默认浏览器不同）。若无法启动，控制台会提示手动打开路径，已生成的网页仍然有效。所有默认路径相对于本项目根目录确定，不依赖 IDE 工作目录。

项目位于工作区的 `销量规律/` 目录，可单独复制或从公开仓库 `https://github.com/rabbittttt/Sales_Patterns` 获取。代码不再依赖 `订单分析` 项目或其 `generate_html` 目录；节假日日历和共享数据路径模块都随本项目放在 `core/` 下。

## 动态网页

双击 `启动动态销量规律.cmd`，或在 IDE 中无参数运行 `dynamic/serve_sales_patterns.py`。根目录 `serve_sales_patterns.py` 保留为兼容转发入口。服务默认地址为 `http://127.0.0.1:8767/`，启动后使用系统默认浏览器打开。运行期间保持服务进程开启，关闭控制台或按 Ctrl+C 结束服务。

后台每 300 秒检查原始汇总表。发现变更后，每秒观察文件状态，连续稳定 60 秒再调用现有分析脚本生成结果。文件继续写入、被替换、暂时缺失或无法读取时重新计算稳定窗口。分析失败或分析期间输入再次变化时，页面继续提供上一次成功结果，并在控制台记录重试信息。

网页在新结果发布后自动刷新，保留当前路由、筛选、证据搜索分页和快速试算输入。当前日期范围覆盖指标全部历史时，刷新后使用更新后的完整范围；自定义日期范围沿用原选择。

`static/` 放单次静态生成入口，`dynamic/` 放动态服务与自动刷新脚本，`core/` 放两者共用的分析、导出与配置模块。根目录 `analyze_sales_patterns.py` 和 `启动销量规律.cmd` 继续提供原来的单次静态生成方式。动态服务复用同一分析逻辑，原始输入仍由 `core/data_paths.py` 定位；迁移时保留完整目录结构。

可选参数包括 `--input`、`--calendar`、`--port`、`--scan-seconds`、`--stable-seconds` 和 `--no-open`。默认扫描和稳定时长分别为 300 秒与 60 秒。重复启动同一项目、同一输入的服务会打开已有实例；端口被其他程序占用时可用 `--port` 指定其他端口。

## 数据和指标

### 源表内容驱动的研究入口

概览提供“首销前两天”“分时节奏”“月份与月内进度”“上市后变化”四个入口。顶部主导航在品牌后展开，图标直接显示原SVG，不再叠加外圈。主视图按研究问题组织，原始证据在完整资料中核对。

- **月内累计进度**：同车型、指标、阶段、批次和来源的完整自然月，分别计算D7、D14、D21及月末累计占比。相对日历进度为累计占比÷已过天数占比；不完整、负值、重复冲突、整月为零均不产生比例。真实0累计量保留。未控制星期、节日或促销，不自动用于预测。
- **首销结构与退订**：读取同一工作簿的“首销D1D2预测指标”和D日曲线，研究早期集中度、订单路径与转化/退订形状。按当前车型分类、车型、日期和阶段筛选，D日、阶段与分母沿用各源表定义；不把源表曲线重新计算成留存大定或锁单。累计快照不跨D日求和，不重复扣减主口径。
- **分时节奏**：只使用完整、唯一、非负、正总量的24小时样本；指标与源表阶段单独选择。小时份额是小时量/同一车型日总量，再按车型等权描述。缺少留存大定分时字段时明确提示，不用其他口径替代。源表覆盖的车型和首销日期有限，不能直接当全部车型的平销规律。

所有扩展只读取指定汇总工作簿，不打开来源列中的外部文件。“首销平销by周”用于资料核对，不和逐日记录叠加。源表缺失时保留模块和原因说明；内网历史数据进入后按实际字段、车型及日期扩展。

自动识别新版“小订首销平销by天”；不存在时兼容旧版“小订及退订逐日”“当前订单逐日”。车型属性和阶段日期读取同一工作簿的“车型基本信息”，数据判定日期读取“说明与来源”。不打开来源文件列指向的外部文件，不修改原始工作簿。兼容2021年以来的数据。

最新版包含日期、代际名、二级代际名（可空）、订单阶段、字段来源，逐字段按原表已合并的最终值读取。二级代际名存在时作为分析车型名，避免同代际不同版本混在一起；属性对应同一原表的车型基本信息。字段来源支持“指标=来源”和“大定/留存大定=来源”形式，每个指标保留各自来源。“小订/平销”“小订/首销”等阶段按指标拆分，小订日期窗口与首销窗口分别使用，不挪用另一阶段的生命周期。空白保持缺失，原表显式0保留。

“小订/首销前”按小订指标归入小订阶段，生命周期仍取小订窗口；首销前的净大定、锁单不强行归入首销或平销。新版“小订期/首销期退订”曲线均属小订退订，首销曲线D1可能是累计值；不与逐日销量相加，不据此重复扣减留存大定。

新版“小订”兼容旧列“小订数量”，分析内仍统一称“小订数量”；“留存大定”兼容“净大定”。值列和字段来源中的新旧名称可交叉匹配；同一指标声明了互相冲突的来源时明确报错。新旧值列并存时优先新版整列，新列空白仍为缺失，不用旧列补齐。小订退订和首销分时核对不用于重算原表的净大定、锁单，也不把小时表或累计曲线叠加到逐日销量。

存在“日期状态”列时，只纳入“已结束日”且早于数据判定日期和运行当天的真实日数据；当日、未来、未结束、空白或未知状态均排除，并在数据审计中记录。旧版没有日期状态时保留原日期过滤规则。明确未知、空白或无法识别的订单阶段不进入规律分析和预测；原始表仍保留这些记录。

兼容上一版日期、订单分析代际名、订单阶段、来源类型、来源文件、来源Sheet的候选表；按实际存在的指标列读取。优先使用新版整张逐日表，不与旧表叠加。保留真实零值、负值和来源文件/Sheet；空白不补零，累计快照、参考曲线、合成/模拟/预测来源及超过数据判定日期或当天的未来记录排除。周汇总不会拆分为日销量或再次相加。

仅对旧候选格式，同车型同日同指标的多来源候选按工作簿说明择一：小订选配优先于小订退订，再到历史小订；首销进行中优先首销订单，首销结束后优先历史整理数据；平销锁单优先锁单逐日来源。未知来源在已知来源之后。同来源或同优先级候选若数量、阶段、批次冲突，则明确报错，不随意累加或取首条。不同发布批次按原始传播名和阶段日期匹配，分类属性冲突仍保留“映射冲突”。

“留存大定/留存大定来源”优先使用；“净大定/净大定来源”兼容读取并统一命名。小订、大定、留存大定、交车锁单等各指标分别分析；首销和平销分别统计，不把当日下订与当日锁单当成逐单转化率。

真实零值保留；缺失不补零。负值保留在观测合计与审计中，但任何一期包含负值时该周期的倍率不计算。锁单滞后相关仅用共同非负日期，0—3天各组使用相同日期。完整零销量月份仍进入年度分析；全年为零时年度指数留空并说明原因。

## 配置

`core/report_config.json`：
- groupBy：auto（默认）、segment（产品档位）、brand（品牌）、energy（能源类型）。
- minGroups/maxGroups：自动选择分类维度的偏好范围，不强行凑组数，不合并或丢弃原始类别。
- mainMetrics：auto（默认）展示本次全部可用指标；可配置为指标名称列表，例如 ["小订数量", "留存大定", "交车锁单"]。未展示的指标会明确列出；配置了本次不存在的指标会报错。

分类只取同一汇总文件“车型基本信息”的原始属性。缺失/冲突单独保留，不通过车型名字猜SUV、价格或能源类型。更换数据可能改变auto选中的分类维度；需要固定口径时显式指定groupBy。

## 结果与验证

首页最前面列出小订、留存大定、锁单在当前范围内发现的候选规律：文字发现、典型比例、适用阶段、车型/周期/年份数和普适性验证情况。跨年候选必须有至少2个共同验证车型、完整训练年度、多个日历周期，并且近期描述与训练和留出年度方向一致；仍需预测回测。未满足时写明局部范围线索或样本不足，不把局部历史规律说成已确认的普适规律。首页后面保留动态车型分类、全部车型及各车型组读数。“规律汇总”保留完整结果，列出典型比例、周期P25/P75、车型数、样本数、不同周期数、覆盖年份和历史/验证年度读数。“全年月份”逐一覆盖1—12月。

所有工作表不冻结窗格。顺序按结论与规律、预测辅助、车型分类与数据说明、明细证据排列：分析总览 → 规律汇总 → 全年月份 → 下订周期规律 → 锁单周期规律 → 预测辅助 → 预测回测明细 → 车型分组 → 数据覆盖与方法 → 周内明细 → 月内明细 → 年度季节性 → 节假日明细 → 生命周期明细 → 锁单滞后 → 月份证据 → 周期比例明细。

网页中的年度季节性和节假日明细按当前筛选展示。即使没有合格样本也保留模块并给出提示。“数据覆盖与方法”展示覆盖范围、负值等排除原因和节假日日历来源。

典型比例：先车型内取中位数，再车型等权取中位数。全部车型的典型比例也采用等权，不能当成销量加权的整体总量比。P25/P75按日历周期的车型间中位数计算，反映波动，不是置信区间。

留出方向验证：根据数据截至日期选取最近一个完整自然年度，以相同车型、阶段、批次、来源且年度观测完整的序列，将该年和更早完整年度比较。不使用最新未完结年。未满足验证条件时明确显示不足。同方向只表示描述性重复，不能直接认定普遍规律、因果效应或预测参数；还需控制改款、价格权益、供给和长期趋势。

节假日日历独立维护。没有配置的年份不判断普通周与节日，日志会提示缺失年份。

## 交互网页与预测参考

网页聚焦小订、留存大定、锁单三个目标，支持车型组/单车型/阶段/日期筛选、日周月年趋势、1—12月及周内规律、相邻周期倍率、节前节中节后、生命周期、留存大定到锁单滞后和可搜索分页证据。小订自动限定为小订期；规律显示典型比例、历史波动范围与有效样本；缺少完整日期或样本时给出说明。车型分类取原表属性，不硬编码品牌或车型名单。

规律用于预测前需要独立检验。新增预测模块按同车型、口径、阶段、批次、来源建立日/周/月序列，以每个历史预测时点之前的数据拟合，和简单基准在相同窗口比较 WAPE、偏差与样本数。最近序列过时或周期未完整时明确提示，不将过去一期伪称下一期预测。网页可查看回测明细，并输入参考销量和单一倍率做情景试算；试算输入由使用者指定，不改变原始观测。

网页保留同次计算的小订、留存大定、锁单、预测辅助及回测结果；历史 Excel 文件不再由主脚本自动更新。

### 网页资料迁移地图

后续以网页为唯一日常查看入口。概览页顶部展示历史规律、验证情况和研究入口；“完整分析资料”保留原 Excel 的证据，并新增月内进度、源表内容地图、D1/D2、D日曲线和分时数据，共24类资料。资料区按指标、车型分类、销售阶段分别筛选，支持搜索、分页和 CSV 原值导出。

主界面保留小订、留存大定与交车锁单三种口径；大定、小转大、直接大定、退订等辅助指标放在完整资料中查阅。完整资料中的记录按当前口径、车型分类、车型、阶段和日期范围追溯；无日期的辅助源记录单列为审计例外，仅供核对，不参与当前日期窗图表。原 Excel 文件保留在原目录，不会删除，也不再由主脚本更新。

历史节假日分析使用双侧同星期对照，可能包含历史事件发生之后的日期，仅用于解释历史，不直接进入滚动预测。周期倍率与P25/P75不等于未来必然增长率或预测置信区间；月份、星期和节日可能重叠，不自动连乘。模型目前不包含价格权益、促销、改款、交付能力等外部特征，需要结合内网真实数据回测后再决定使用。

网页采用列式数据与重复文本字典存储，以减少多年数据的体积；不舍入原始值，不随机抽样丢弃证据。动态表格分页只影响呈现。HTML 内嵌业务数据，迁移和分享范围按源文件相同要求处理。

## 上市后销量节奏

上市后销量节奏取自“鸿蒙智行销量数据汇总”的“小订首销平销by天”，覆盖首销及其后的平销，留存大定、锁单分别研究；小订只在小订期研究。订单阶段中的小订标签独立判断；“小订/首销前”“小订/首销”“小订/平销”“小订/阶段未知”按指标拆分，不将整行统一归入一个阶段。首销包含开始日和结束日。小订边界缺失不单独作为删除小订观测的理由；阶段未知的订单不进入首销或平销规律。

以原表车型元数据的首销开始日作为上市锚点，平销也沿用该上市批次。上市周按D1–D7、D8–D14依次延伸；上市月按首销日逐月划分，月末锚点截到目标月末，不是自然月。不固定只看第2、3周，而是展示实际数据触及的所有周期。日期缺口不补零，没有可靠上市锚点的平销记录不凭空接到其他批次。

每个周期列出观测合计、覆盖天数、日均量和阶段。相邻周期同时保留总量比与日均比，规律汇总采用日均比，避免不同月份天数造成误判。只有同车型、上市批次、口径、来源的完整非负周期且前期大于0才计算倍率；来源切换、缺日、负值和零分母均保留证据并显示不可比。跨越首销结束日的周期、以及由首销转为平销的比较标为“跨阶段”，不并入纯首销或纯平销规律。

网页“规律研究 → 上市后销量节奏”提供周/月粒度和首销至平销的趋势、相邻周期比例及逐车型证据。进入模块默认查看“首销及平销”，保留车型和日期筛选；单选首销或平销只看相应阶段的完整周期。退出该模块恢复单阶段筛选。各周期可能覆盖不同车型，趋势同时标明样本量，不能将样本组成变化当作全市场增长或衰退。“生命周期明细”提供全部周期观测、总量比和日均比。

典型值先车型内中位数再车型等权，历史分位数只是批次波动。结果属于上市批次描述，尚未做跨批次留出验证，不能直接当作新车型预测系数。浏览器标签页图标内嵌HTML，离线使用无需复制图标文件。

## 节假日按筛选范围汇总

网页的节假日主图和主表按左侧口径、车型分类、车型、销售阶段及日期筛选汇总。选择全部车型时显示“鸿蒙智行全部车型”，同时列出有效样本车型与所选车型数量；不把有完整对照的部分车型宣称为全量。

每个节日事件固定一组具有完整节前7日、节中及节后7日观测和同星期控制基准的车型。每天先合计这些车型的实际量与控制基准量，计算“当日实际合计 / 当日基准合计”，再分别对节前、节中、节后的每日倍率取均值。留存大定、小订和锁单分开计算，零实际值保留，缺日、负值及冲突记录不补造。它与逐车型指数简单平均不同；单车型时与原始指数一致。

逐车型结果和来源明细保留在汇总下方。历史控制日期可能在所选节日之后，这些指数用于历史解释，不直接作为预测系数；日期窗只含节日当天或样本没有足够控制日期时，页面显示不足原因。
### 口径与审计更新

- 首销结构随当前车型、日期和阶段范围计算；辅助指标保留源表名称，不把小订、留存大定、锁单混为同一口径。
- 首销前、阶段未知仅作为证据中的阶段标签保留，规律统计默认只纳入首销/平销；阶段未知或日期缺失记录可在证据页核对，但不进入当前日期窗图表。
